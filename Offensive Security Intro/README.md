# TryHackMe – Offensive Security Intro

## What I learned

- **Think like an attacker** : adopt an offensive mindset to anticipate vulnerabilities before real hackers do.
- **Using `dirb`** : a directory brute‑forcing tool to discover hidden pages on a website.
- **Manual URL discovery** : once a path is found (`/bank-transfer`), explore it directly in the browser.
- **Attacking an admin panel** : accessing an unprotected interface that allows data manipulation (e.g., adding money to a fake bank account).

## Technical skills acquired

- Passive and active web reconnaissance
- Directory enumeration with `dirb`
- URL manipulation
- Understanding broken access control (exposed admin panel)

## Environment

- TryHackMe – Offensive Security Intro room
- FakeBank (deliberately vulnerable banking application)
